# Icon Source Assets

This directory serves as the source of truth for all SVG icons in FizzyIcons.

## Folder Structure

Each icon should have its own dedicated subfolder under `icons/`:

```
icons/
└── [icon-name]/
    ├── outline.svg     # Outline variant SVG
    ├── solid.svg       # Solid variant SVG
    ├── colored.svg     # Multi-color variant SVG
    └── metadata.json   # Icon metadata (tags, category, color slots, etc.)
```
